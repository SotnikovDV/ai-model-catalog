# Подбор моделей

AI-ассистент помогает выбрать LLM из **локального каталога** по описанию задачи на естественном языке.

Пример запроса: «недорогая модель для RAG на русском с большим контекстом».

Подбор идёт только среди моделей каталога — не из произвольного интернета.

## Как пользоваться

1. Опишите задачу в поле ввода.
2. Нажмите **«Подобрать модели»**.
3. Прочитайте краткий вывод ассистента и список кандидатов с обоснованием.
4. При необходимости откройте полный список («С комментариями») или каталог с подобранными карточками.

Для подбора используется **аналитическая модель** из настроек админки (не модель из карточки каталога).

## Как работает алгоритм

Подбор идёт в два этапа.

### 1. Отбор кандидатов

Сначала система отбирает модели, которые:

- не скрыты в каталоге;
- имеют статус доступности **«Инференс»** (реально отвечают через API).

Затем по тексту запроса (и истории диалога, если есть) оценивает релевантность:

- совпадения слов с названием, семейством, описанием, тегами и use-cases;
- подсказки по смыслу запроса: бюджет, RAG, код, изображения, русский язык, скорость, reasoning, JSON/tools, поиск в интернете.

В аналитическую модель передаётся не весь каталог, а **до 40 лучших кандидатов**.

Если по ключевым словам никто не «зацепил», берутся сильные универсальные модели (по качеству задач и цене).

### 2. Ранжирование и комментарии

Аналитическая модель:

- выбирает до 8 наиболее подходящих вариантов;
- пишет краткий общий вывод;
- для каждой модели даёт короткое обоснование на русском.

Учитываются цена, размер контекста, модальность, рейтинги качества, use-cases и поддержка web-search — если это следует из запроса.

Если ответ модели получился слишком коротким или пустым, список добирается автоматически из уже отобранных кандидатов.

## Что вы увидите в ответе

| Элемент | Смысл |
|---------|--------|
| Краткий вывод | Общий совет по выбору |
| Список моделей | Ранг, ссылка на карточку, бейджи и rationale |
| «Показать карточками» | Каталог только с подобранными моделями |
| «С комментариями» | Полная страница результатов с обоснованиями |

Цены в бейджах — стоимость за 1M входных + 1M выходных токенов в рублях.

## Ограничения

- Не тестирует кандидатов «вживую» во время подбора — опирается на данные каталога и статус inference.
- Не учитывает личные избранные модели.
- При одинаковом запросе формулировки ответа могут немного отличаться.
- Без моделей со статусом «Инференс» подбор недоступен: сначала запустите проверку inference в админке.

## Советы по формулировке запроса

Чем конкретнее задача, тем полезнее результат. Указывайте, например:

- бюджет («недорого», «бесплатно»);
- язык («на русском»);
- сценарий (RAG, код, чат, vision);
- ограничения (большой контекст, низкая задержка, JSON/tools, поиск в интернете).
